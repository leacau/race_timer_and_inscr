# **App Name**: RaceTimer Pro

## Core Features:

- Category Creation: Define race categories based on age, gender, and distance.
- Participant Auto-Categorization: Automatically assign participants to the correct category based on their data.
- Timing: Accurately record start and finish times for each participant.
- Excel Import: Import participant data from Excel files (.xlsx, .csv).
- Role-Based Access Control: Implement two access levels: read-only and write access for data management.
- Data Management: Store participant data including name, surname, ID, gender, birth date, age, distance, and calculated category in a Cloud SQL database.
- Age Auto-Calculation: Automatically calculate participant age from their birth date.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to evoke trust and stability, suitable for a timing application.
- Background color: Light Gray (#E8EAF6), providing a neutral backdrop to ensure readability.
- Accent color: Orange (#FF9800) to highlight key actions such as starting and stopping the timer.
- Body and headline font: 'Inter', a grotesque sans-serif, for clear, modern readability in both headlines and body text.
- Use clear, modern icons to represent actions and categories.
- Mobile-first layout, ensuring key information is always accessible.
- Subtle animations to provide feedback during timing actions (e.g., a pulse effect when the timer is running).
